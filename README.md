# Pakka (prototype)

Clickable prototype for the Scapia product internship assignment.

**The plan:** a weekend trip with friends. **The user:** the organiser, the person who says "we should go" in the group chat and then ends up chasing everyone.

**The idea:** most trips die because nothing gets formalised. Pakka makes three decisions concrete, in this order:

1. **Where.** Everyone privately picks the vibe they're up for and a budget. Pakka shows the places that fit the most people, and only says how many it doesn't fit (budgets are never shown).
2. **When.** Everyone marks days green (I'm there), orange (I can make it work) or red (can't). Pakka finds the windows where the most people overlap.
3. **Money.** Everyone puts a deposit into a shared pot. If someone bails later, their deposit goes to the people still going. The screen at the end lets you try it.

## Run it

It's plain HTML, CSS and JS. Open `index.html`, or host the folder anywhere static.

On GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

Jump straight to a screen with `index.html#1` to `#5`.

## Notes

- Friends, budgets, availability and payments are made up. No real money moves.
- Costs are rough per-head estimates from Bengaluru.
- Window and place ranking run live, so changing your own answers changes the results.
